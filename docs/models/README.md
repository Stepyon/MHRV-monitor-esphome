# MVHR temperature-probe duct adapter

The `MHRV_sensor_adapter.stl` file is the 3D-printable duct adapter used to mount a waterproof DS18B20 temperature sensor in an MVHR duct. The project uses **four identical adapters**, one for each duct (outdoor, supply, extract, exhaust).

Print in **ASA** (used in the example installation) or a suitable temperature-resistant plastic such as **ABS** or **PETG**. Do not use PLA. Test-fit the adapter in scrap material before drilling the real duct. The narrow fitting section is approximately 9 mm and is intended for a snug, sealed fit. Avoid forcing the part because it can crack.

See the [installation guide](../../README.md#install-the-temperature-probes-in-the-mvhr-ducting) for drilling, adhesive, correct sensor insertion and placement.

*The STL is supplied by the project's author; the installation is an example and is not manufacturer-approved.*
